HospitAll UI Prototype

Developer Reference - Select a role to explore the complete workflow. Each HTML file contains all screens, forms, and API references for that role.

Dr
Doctor
Full consultation workflow with clinical notes, diagnostics, diagnosis, prescriptions, and follow-up planning
Screens: Dashboard, Queue, Consultation (Clinical Notes/Diagnostics/Diagnosis/Medications/Treatment Plan), Video/Audio Calls, Reception
Rc
Receptionist
Appointment booking, patient registration, check-in queue, payment collection (UPI/Razorpay/Cash)
Screens: Dashboard, Appointments, Book New, Check-in Queue, Patient Registry, Register Patient, Payments
Nu
Nurse
OPD vitals recording, IPD medication administration (MAR), vitals charting, nursing notes
Screens: Dashboard, Vitals Queue, Record Vitals (all fields), IPD MAR, IPD Vitals, Admission Notes
Ad
Admin / Org Admin
User management, IPD bed management, pharmacy billing, emergency dept, org settings, reports
Screens: Dashboard, Users, Doctors, Patients, IPD (Ward/Room/Bed), Pharmacy, Emergency, Labs Inbox, Settings, Reports
Pt
Patient (User)
In-person appointment booking (4-step), online consultation (teleconsult/now), lab ordering with geo-nearby, records, prescriptions, claim flow
Screens: Dashboard, Appointments, Book In-Person (Org/Doctor/Slot/Pay), Book Online (Intake/Doctor/Slot/Pay), Records, Prescriptions, Lab Orders, Claim, Emergency
Rx
Pharmacy
Full pharmacy operations: sales, purchases/GRN, prescription dispensing with Schedule H verification, GST invoicing, batch/expiry tracking (Telangana compliant)
Screens: Overview, Products, Suppliers, Customers, Sales, Purchases, Returns, Damages, Stock Adj., Reports, Rx Dispense, Settings, Invoice Print
